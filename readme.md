# us_checker

Телеграм-бот, который сам ищет свободные оригинальные юзернеймы: только `a-z`, без цифр и `_`.

Словарные слова Telegram почти все держит в резерве (при попытке поставить пишет «некорректный юз»), поэтому бот генерирует **несуществующие, но звучные** имена и проверяет их.

## Генератор (`us_checker/gen/`)

20 стратегий, у каждой своё звучание. Выдача перемешивается по весам:

| Стратегия | Что делает | Примеры |
|---|---|---|
| `markov_en/it/es/fr/pt/fi/id/tr/ru` | буквенная цепь Маркова, обученная на словаре языка: новые слова «с акцентом» | spontano, risoldi, nellinen, kurazu, polniki |
| `markov_mix` | цепь по смеси всех языков | shomalita, valahte |
| `syll_elven/dark/future/soft/east` | конструктор из слогов в разных стилях | lanyaes, veskog, vyzern, jubajan, rinzen |
| `classical` | греко-латинская основа + окончание | lumora, helyon, orphien |
| `twist` | редкое реальное слово с подменой букв | obsydian-подобные |
| `blend` | слияние двух слов по общему куску | lunar+arcade → lunarcade |
| `reverse` | перевёрнутое слово | dragon → nogard |
| `affix` | корень + стильный суффикс | godeless, noxelle |

Отсев только технический: настоящие слова любых языков (они в резерве), «опечатки» (одна буква от частого слова), нечитаемые стыки. Стоп-листа по смыслу нет — что не нравится, скипаешь сам через `/bad`.

Короткие имена генерятся чаще длинных. Одинаковые начала и окончания не идут подряд.

## Проверка

Генерация идёт в отдельном потоке, проверку делают `WORKERS` параллельных воркеров с общим лимитом `RPS` запросов в секунду к `https://t.me/<юз>`. Если на странице нет имени, юз никому не принадлежит, и бот присылает находку. На 429 все воркеры вместе ждут. Каждые 500 проверок бот сверяется с `@durov`: если тот «свободен», значит что-то сломалось, и сканер встаёт на паузу.

> ⚠️ «Свободен» значит, что на t.me пусто. Финальная проверка — поставить юз в настройках.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN от @BotFather и свой ADMIN_IDS
.venv/bin/python -m us_checker
```

Первый запуск прогревает генератор около 10 секунд.

## Команды

| Команда | Что делает |
|---|---|
| `/scan` | запустить поиск |
| `/pause` | пауза |
| `/free` | найденные свободные юзы |
| `/preview` | 40 свежих кандидатов без проверки — посмотреть стиль |
| `/styles` | какая стратегия сколько нашла |
| `/bad name1 name2` | Telegram не дал поставить / не нравится — больше не показывать |
| `/check velora` | проверить один юз |
| `/add name1 name2` | проверить свои варианты вне очереди |
| `/stats` | прогресс и скорость |
| `/stop` | не присылать находки |

## Настройки (`.env`)

- `MIN_LEN` / `MAX_LEN` — длина (по умолчанию 5–9);
- `WORKERS` — параллельные проверки (по умолчанию 4);
- `RPS` — общий лимит запросов в секунду (по умолчанию 3; ловишь 429 — уменьши);
- `STRATEGIES` — оставить только нужные стратегии по префиксу, например `syll,classical,markov_it`.

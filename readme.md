# us_checker

Телеграм-бот, который сам ищет свободные изысканные юзернеймы: только `a-z`, без цифр и `_`. Ищет не словарные слова (их Telegram почти все зарезервировал, и при попытке поставить пишет «некорректный юз»), а придуманные, но звучные формы: `godeless`, `godelesse`, `incelious`, `noxelle`, `lunesse`.

## Как работает

1. **Кандидаты (`SOURCES=styled`, по умолчанию).** Генератор `us_checker/stylize.py`:
   - сильные корни из `us_checker/data/roots.txt` (god, sin, nox, lux, incel, velvet, karma…) + эстетичные суффиксы (`-less`, `-lesse`, `-ious`, `-esse`, `-elle`, `-ique`, `-ora`, `-ix`…);
   - мутации настоящих слов: `godless → godeless → godelesse`, `famous → famious`;
   - выкидывает всё, что есть в словаре (это «очевидные» слова, они в резерве), нечитаемую кашу (триграммная модель английских букв) и уродливые стыки вроде `ee`.

   Длина 5–9, только `a-z`, без окончания `bot`. Старые режимы тоже остались: `premium`, `translit`, `dict` (см. `.env.example`).
2. **Ранжирование.** Сила корня + красота суффикса + «похожесть на слово» − штраф за длину. Один корень не забивает весь топ. Слова из `/add` идут первыми.
3. **Проверка.** Бот запрашивает `https://t.me/<юз>`. Если на странице нет имени, юз никому не принадлежит.
4. **Уведомление.** Каждый новый свободный юз бот присылает в чат.

> ⚠️ «Свободен» значит, что на t.me пусто. Юз всё равно может быть в резерве у Telegram или на кулдауне. Финальная проверка — поставить его себе в настройках. Нерабочие отправляй боту через `/bad`, он их больше не покажет.

Свои корни можно дописать в `us_checker/data/roots.txt` (формат `корень:вес`, вес 1–3).

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN от @BotFather и свой ADMIN_IDS
.venv/bin/python -m us_checker
```

Свой Telegram user id можно узнать у @userinfobot. Если задать `ADMIN_IDS`, ботом сможешь пользоваться только ты.

## Команды

| Команда | Что делает |
|---|---|
| `/scan` | запустить поиск |
| `/pause` | пауза |
| `/free` | найденные свободные юзы по ценности |
| `/check godeless` | проверить один юз |
| `/bad name1 name2` | отметить юзы, которые Telegram не дал поставить |
| `/preview` | топ очереди кандидатов |
| `/add word1 word2` | добавить свои слова в приоритет |
| `/stats` | прогресс |
| `/stop` | не присылать находки |

## Настройки (`.env`)

Все параметры описаны в `.env.example`. Главные:
- `SOURCES` — откуда брать кандидатов (по умолчанию `styled`);
- `MIN_LEN` / `MAX_LEN` — длина юзов (по умолчанию 5–9);
- `CHECK_DELAY` — пауза между запросами к t.me (по умолчанию 1.5 с);
- `RECHECK_DAYS` — через сколько дней перепроверять занятые юзы (освобождаются).

# us_checker

Телеграм-бот, который сам ищет свободные «блатные» юзернеймы: только `a-z`, без цифр и `_`, короткие реальные слова.

## Как работает

1. **Кандидаты.** Берутся из трёх источников:
   - ручной список ходовых слов (`us_checker/data/premium.txt`): крипта, деньги, статус, tech, lifestyle;
   - транслит (`us_checker/data/translit.txt`): bratva, dengi, zoloto…;
   - частотный английский словарь [wordfreq](https://pypi.org/project/wordfreq/).

   Фильтр: длина 5–7 (Telegram не даёт занять короче 5), только `a-z`, без окончания `bot`, без служебных слов и множественного числа.
2. **Ранжирование.** Частотность слова + бонус за ручной список − штраф за длину. Первыми проверяются самые ценные.
3. **Проверка.** Бот запрашивает `https://t.me/<юз>`. Если на странице нет имени, юз никому не принадлежит.
4. **Уведомление.** Каждый новый свободный юз бот присылает в чат.

> ⚠️ «Свободен» значит, что на t.me пусто. Юз может быть зарезервирован под Fragment или стоять на кулдауне после освобождения. Финальная проверка — поставить его себе в настройках.

## Запуск

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env   # впиши BOT_TOKEN от @BotFather и свой ADMIN_IDS
.venv/bin/python -m us_checker
```

Свой Telegram user id можно узнать у @userinfobot. Если задать `ADMIN_IDS`, ботом сможешь пользоваться только ты.

## Команды

| Команда | Что делает |
|---|---|
| `/scan` | запустить поиск |
| `/pause` | пауза |
| `/free` | найденные свободные юзы по ценности |
| `/check money` | проверить один юз |
| `/add word1 word2` | добавить свои слова в приоритет |
| `/stats` | прогресс |
| `/stop` | не присылать находки |

## Настройки (`.env`)

Все параметры описаны в `.env.example`. Главные:
- `MIN_LEN` / `MAX_LEN` — длина юзов (по умолчанию 5–7);
- `CHECK_DELAY` — пауза между запросами к t.me (по умолчанию 1.5 с);
- `RECHECK_DAYS` — через сколько дней перепроверять занятые юзы (освобождаются).
